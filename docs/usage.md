# 使用指南

Aura 用于阅读自己导入的 TXT 文件。书籍、阅读进度与外观保存在当前浏览器中，不需要账户。

## 打开 Aura

日常使用可以直接打开[在线版](https://aura.allurx.io)，也可以安装为应用。需要不联网打开时，从 [GitHub Releases](https://github.com/allurx/aura/releases) 下载 portable HTML，用浏览器打开该文件即可。

### 安装应用

联网打开 Web 版，通过浏览器地址栏或菜单提供的安装入口添加到桌面或主屏幕，按浏览器提示完成。

- Chrome、Edge 等浏览器可能在地址栏显示安装图标，也可在浏览器菜单查找“安装 Aura”“安装此站点为应用”或“添加到主屏幕”等选项；是否提供入口取决于浏览器及当前安装资格。
- iPhone、iPad 可在 Safari 的分享菜单选择“添加到主屏幕”；Mac Safari 可在支持的系统中通过“文件 → 添加到程序坞”添加。
- 菜单没有安装选项时，可以继续使用网页或下载 portable。

安装需要 HTTPS（本机开发预览可使用 localhost）。安装提供桌面或主屏幕入口，重新打开 Web 版仍需联网；需要离线打开时请使用 portable。portable 不提供安装入口。

安装不提供账户同步或书籍备份。不同浏览器、设备或独立应用环境可能使用不同的存储空间，不应假定安装后会自动带入网页中的书架；请保留原始 TXT。

### 选择下载文件

下表中的 `vX.Y.Z` 代表所选 Release 的版本号，下载时以该页面附件的实际文件名为准。个人离线阅读选择普通 portable 版即可。

| 文件                                   | 用途                                           |
| -------------------------------------- | ---------------------------------------------- |
| `aura-portable-vX.Y.Z.html`            | 普通单文件版，可直接以 `file://` 打开。        |
| `aura-portable-obfuscated-vX.Y.Z.html` | 混淆单文件版，打开方式与普通版相同。           |
| `aura-web-vX.Y.Z.zip`                  | 普通 Web 包，用于通过 HTTP(S) 提供网页的场景。 |
| `aura-web-obfuscated-vX.Y.Z.zip`       | 混淆 Web 包，使用方式与普通 Web 包相同。       |
| `aura-vX.Y.Z-SHA256SUMS.txt`           | 上述四个文件的 SHA-256 校验清单。              |

普通版与混淆版提供相同的阅读功能。GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码包，不能作为 portable HTML 直接阅读。

使用 Web ZIP 时，解压后将根目录内容作为完整产物部署到 HTTP(S) 站点根路径；当前 Web 构建不适用于直接放在站点子路径下。

### 校验下载文件

同时下载同一 Release 的校验清单，将所下载文件的 SHA-256 与清单中该文件对应的校验值进行比较。例如，在 Windows PowerShell 中进入下载目录，替换为实际文件名后运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\aura-portable-vX.Y.Z.html"
```

输出的 `Hash` 应与清单中该文件对应的校验值一致，字母大小写不影响比较。若不一致，重新下载后再检查。

## 导入书籍

首次使用时书架为空，导入自己的 TXT 后开始阅读。

1. 在书架选择“全部书籍”或一个分类。
2. 点击顶部“导入 TXT”，选择一本或多本 `.txt` 文件；窄屏上可能只显示加号图标。
3. 等待当前文件的处理状态结束。全部成功会短暂提示；部分文件未导入或批次中断时，对话框会显示结果和原因，关闭后返回书架。

在具体分类内导入会归入该分类；在“全部书籍”中导入会归入“收藏”。同一内容可以重复导入，每本书分别保存阅读进度。批次中断时，已经成功导入的书籍会保留。

### 编码注意事项

Aura 自动识别 UTF-8、GB18030、Big5 和带 BOM 的 UTF-16，不提供手动选择编码。无法可靠识别或严格解码的文件会被拒绝导入。遇到编码提示时，请用文本编辑器将原文件另存为 UTF-8 后重试；只更改文件扩展名不能转换编码。

## 查找与整理

- 桌面左侧选择分类；手机点击左上角导航按钮打开分类列表。
- 顶部搜索框按书名筛选**当前分类**。需要搜索整个书架时，先选择“全部书籍”。
- 点击书封阅读。书目下方显示已保存的章节位置，打开后恢复到具体段落。
- 直接选择书目下方的目标分类即可移动，无需再次确认。
- 删除按钮会先确认书名，并删除该书的阅读进度；导航底部的“清空书架”会在确认后删除所有分类中的书籍与进度。

从阅读器返回时，会恢复当前分类、搜索、列表位置及刚才打开的书籍焦点。在书架菜单选择“关于 Aura”，再点击“项目源码”可打开[Aura 项目仓库](https://github.com/allurx/aura)，查看说明或反馈问题，需要联网；手机先打开左上角导航。

## 阅读与目录

桌面阅读器在阅读区域外的右侧竖排显示操作按钮，依次分为“上一章 / 下一章 / 目录”“外观 / 全屏”“书架”三组，以分割线区分，最下方单独显示全书阅读进度。上下信息栏隐藏，让正文占据完整阅读高度。全屏可用性取决于浏览器及当前打开环境。

手机、窄屏或触摸设备默认隐藏上下工具栏。上下滑动正文阅读，轻点正文中间区域显示或收起工具：顶部显示书名，底部显示当前章节、全书阅读进度，并按“目录 → 外观 → 全屏 → 书架”的顺序集中提供操作。键盘可用 `Tab` 找到“显示阅读工具”入口。

移动工具显示时覆盖在正文之上，正文尺寸和阅读位置保持不变。显示后可用 `Escape` 收起，切换章节后也会回到沉浸阅读；滚动阅读或长按选字不会开关工具。调整窗口大小时保留可用的操作入口和焦点。目录或外观面板打开时，`Escape` 先关闭当前面板。

点击“目录”后可以按章节名称查找，选择章节进入阅读；关闭目录或按 `Escape` 返回正文。桌面的目录和外观面板从右侧打开，移动布局从底部打开。

桌面点击右侧“上一章”“下一章”切章。移动布局中，轻点正文左侧前往上一章、右侧前往下一章；向右横向轻扫切换上一章，向左横向轻扫切换下一章。这些操作切换整个章节，正文中部轻点用于开关工具，上下滑动用于阅读当前章。正文获得焦点时，也可以使用左右方向键切章。

阅读位置会自动保存，再次打开同一本书时接着上次的位置阅读。桌面侧栏与移动底栏使用同一份全书阅读进度，百分比保留两位小数。

## 调整外观

书架的“外观”在顶部，手机书架上可能只显示设置图标。桌面阅读器直接点击右侧“外观”；手机、窄屏或触摸设备先轻点正文中间区域，再点击底部“外观”。

书架提供主题选择。阅读器面板分为“主题”和“常规设置”：主题控制整体配色，常规设置提供字号、行距、段间距、文字颜色、阅读背景，以及桌面阅读宽度。

默认主题为“晴空”，另有浅色的“海盐”“薄荷”“杏桃”“花信”“纸页”和深色的“星夜”“暮色”“深海”。主题以色样横向排列，可以横向浏览全部选项。

调整时可以实时预览，完成单项操作后保存；关闭面板会取消尚未提交的预览。手动指定的阅读设置优先于主题，切换主题不会清除这些设置。窄屏按可用空间显示阅读内容，保留桌面阅读宽度的首选值。

每个设置项旁的重置图标只恢复该项；“常规设置”旁的重置图标恢复全部阅读常规设置并保留主题。重置主题也会保留常规设置。未修改的项目会显示淡色重置图标。

书架与阅读器的外观分别保存。“重置当前页面”恢复当前页面的主题和全部常规设置，不影响另一个页面，也不删除书籍或阅读进度。

## 本地数据与 portable 注意事项

- 导入的文本与阅读进度保存在当前浏览器的本地数据库中，不会上传；外观也保存在当前浏览器中。
- 清除网站数据、浏览器清理、更换浏览器配置或存储空间不足可能导致数据不可用，请保留原始 TXT 文件。
- 在线版按访问地址区分本地存储；不同浏览器或不同地址之间不会自动同步书架。
- portable HTML 包含应用本身，不包含已导入的书籍与阅读进度。复制 HTML 到另一台设备不等于复制书架；应同时保留 TXT 文件，并在新环境重新导入。
- 不同 portable 文件路径下的本地存储行为由浏览器决定。移动或重命名 HTML 后，不应假定仍能访问原来的书架。

## 开源许可

在书架菜单选择“关于 Aura”，查看 Aura 与第三方组件的名称、许可类型和官方来源链接；手机先打开左上角导航。全文默认收起，需要时展开对应项目查看。

完整许可证与第三方声明随应用提供，portable 版无需联网即可查看本地全文；访问官方来源链接需要联网。
