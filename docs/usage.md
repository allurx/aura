# 使用指南

Aura 用于阅读自己导入的 TXT 文件。书籍、阅读进度与外观保存在当前浏览器中，不需要账户。

## 打开 Aura

日常使用可以直接打开[在线版](https://aura.allurx.io)。需要不联网打开时，从 [GitHub Releases](https://github.com/allurx/aura/releases) 下载 portable HTML，用浏览器打开该文件即可。

### 选择下载文件

下表中的 `vX.Y.Z` 代表所选 Release 的版本号，下载时以该页面附件的实际文件名为准。个人离线阅读选择普通 portable 版即可。

| 文件                                   | 用途                                           |
| -------------------------------------- | ---------------------------------------------- |
| `aura-portable-vX.Y.Z.html`            | 普通单文件版，可直接以 `file://` 打开。        |
| `aura-portable-obfuscated-vX.Y.Z.html` | 混淆单文件版，打开方式与普通版相同。           |
| `aura-web-vX.Y.Z.zip`                  | 普通 Web 包，用于通过 HTTP(S) 提供网页的场景。 |
| `aura-web-obfuscated-vX.Y.Z.zip`       | 混淆 Web 包，使用方式与普通 Web 包相同。       |
| `aura-vX.Y.Z-SHA256SUMS.txt`           | 上述四个文件的 SHA-256 校验清单。              |

普通版与混淆版提供相同的阅读功能。GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码包，不能作为 portable HTML 直接阅读。

使用 Web ZIP 时，解压后将根目录内容作为完整产物部署到 HTTP(S) 站点根路径；当前 Web 构建不适用于直接放在站点子路径下。

### 校验下载文件

同时下载同一 Release 的校验清单，将所下载文件的 SHA-256 与清单中该文件对应的校验值进行比较。例如，在 Windows PowerShell 中进入下载目录，替换为实际文件名后运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\aura-portable-vX.Y.Z.html"
```

输出的 `Hash` 应与清单中该文件对应的校验值一致，字母大小写不影响比较。若不一致，重新下载后再检查。

## 导入书籍

1. 在书架选择“全部书籍”或一个分类。
2. 点击顶部“导入 TXT”，选择一本或多本 `.txt` 文件；窄屏上可能只显示加号图标。
3. 等待当前文件的处理状态结束。成功导入会短暂提示；未导入的文件会保留可展开的明细。

在具体分类内导入会归入该分类；在“全部书籍”中导入会归入“收藏”。同一内容可以重复导入，每本书分别保存阅读进度。批次中断时，已经成功导入的书籍会保留。

### 编码注意事项

Aura 自动识别 UTF-8、GB18030、Big5 和带 BOM 的 UTF-16，不提供手动选择编码。无法可靠识别或严格解码的文件会被拒绝导入。遇到编码提示时，请用文本编辑器将原文件另存为 UTF-8 后重试；只更改文件扩展名不能转换编码。

## 查找与整理

- 桌面左侧选择分类；手机点击左上角导航按钮打开分类列表。
- 顶部搜索框按书名筛选**当前分类**。需要搜索整个书架时，先选择“全部书籍”。
- 点击书封阅读。书目下方显示已保存的章节位置，打开后恢复到具体段落。
- 直接选择书目下方的目标分类即可移动，无需再次确认。
- 删除按钮会先确认书名，并删除该书的阅读进度；导航底部的“清空书架”会在确认后删除所有分类中的书籍与进度。

从阅读器返回时，会恢复当前分类、搜索、列表位置及刚才打开的书籍焦点。导航底部的“阅读帮助”可打开内置简明手册；手机先打开左上角导航。手册分为“快速开始、查找整理、阅读接续、主题与外观、本地与离线、帮助交流”六章，可在阅读器的“目录”中直接跳转。

## 阅读与目录

桌面阅读器顶部显示书名，左上角返回书架、右上角打开目录，左下角调整外观、右下角切换全屏。全屏可用性取决于浏览器及当前打开环境。

手机或触摸设备默认隐藏上下工具栏，上下滑动正文阅读。轻点正文中间区域显示或收起工具：顶部显示书名，底部按“书架 → 目录 → 外观 → 全屏”的顺序集中提供操作。滑动或长按选字不会开关工具；切换章节后会回到沉浸阅读。键盘可用 `Tab` 找到“显示阅读工具”入口，工具显示时可用 `Escape` 收起。

工具栏显示当前章节与阅读进度。点击“目录”后可以按章节名称查找，选择章节进入阅读；关闭目录或按 `Escape` 返回正文。手机上的目录和外观以底部面板打开。章节末尾提供“上一章”“下一章”按钮，正文获得焦点时也可以使用左右方向键切章。

阅读位置会自动保存，再次打开同一本书时接着上次的位置阅读。进度显示用于了解阅读位置；切换章节使用目录或章末按钮。

## 调整外观

书架的“外观”在顶部，手机书架上可能只显示设置图标。桌面阅读器的入口在左下角；手机或触摸设备先轻点正文中间区域，再点击底部“外观”。默认主题为“晴空”，另有“海盐”“薄荷”“杏桃”“花信”和深色的“星夜”。在同一面板内选择主题，或选择具体区域调整字号、颜色、留白等可用选项。阅读正文还可调整行距，桌面可调整阅读宽度；数值控件按区域提供相应范围。

调整时可以实时预览，完成单项操作后保存；关闭面板会取消尚未提交的预览。具体区域的显式设置优先于主题，切换主题不会清除这些设置。

书架与阅读器的外观分别保存。“重置当前页面”只恢复当前页面的默认外观，不影响另一个页面，也不删除书籍或阅读进度。

## 本地数据与 portable 注意事项

- 导入的文本与阅读进度保存在当前浏览器的本地数据库中，不会上传；外观也保存在当前浏览器中。
- 清除网站数据、浏览器清理、更换浏览器配置或存储空间不足可能导致数据不可用，请保留原始 TXT 文件。
- 在线版按访问地址区分本地存储；不同浏览器或不同地址之间不会自动同步书架。
- portable HTML 包含应用本身，不包含已导入的书籍与阅读进度。复制 HTML 到另一台设备不等于复制书架；应同时保留 TXT 文件，并在新环境重新导入。
- 不同 portable 文件路径下的本地存储行为由浏览器决定。移动或重命名 HTML 后，不应假定仍能访问原来的书架。
