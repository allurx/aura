# 使用指南

Aura 用于阅读自己导入的 TXT 和 EPUB 文件。无需账户，书籍、阅读进度与外观保存在当前浏览器中。

## 打开 Aura

日常使用可以直接打开[在线版](https://aura.allurx.io)。需要离线打开时，从 [GitHub Releases](https://github.com/allurx/aura/releases) 下载 portable HTML，用浏览器打开该文件。

### 安装应用

联网打开 Web 版后，可以通过浏览器的安装入口添加到桌面或主屏幕。是否提供入口取决于浏览器及系统支持，具体操作见官方说明：

- [Chrome：安装 Web 应用](https://support.google.com/chrome/answer/9658361?hl=zh-Hans&co=GENIE.Platform%3DDesktop)
- [Edge：将网站安装为应用](https://support.microsoft.com/zh-cn/edge/install-manage-or-uninstall-apps-in-microsoft-edge)
- Safari：[iPhone 添加到主屏幕](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)、[Mac 添加到程序坞](https://support.apple.com/zh-cn/guide/safari/ibrw9e991864/mac)

没有安装入口时，继续使用网页即可。安装后的 Aura Web 版仍需联网打开；portable 用于离线打开，不提供应用安装入口。主屏幕模式也不等同于网页全屏，系统状态栏与手势区域由设备管理。

安装不提供书籍备份或跨设备同步。网页与独立应用窗口可能使用不同的存储空间，安装后应先确认书架是否可用，并保留原始书籍文件。

### 选择下载文件

个人离线阅读选择 portable 版即可。下表中的 `vX.Y.Z` 为所选 Release 的版本号，下载时以附件的实际文件名为准。

| 文件                         | 用途                              |
| ---------------------------- | --------------------------------- |
| `aura-portable-vX.Y.Z.html`  | 单文件版，用浏览器直接打开。      |
| `aura-web-vX.Y.Z.zip`        | Web 包，用于部署网站。            |
| `aura-vX.Y.Z-SHA256SUMS.txt` | 上述两个文件的 SHA-256 校验清单。 |

GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码包，不能作为 portable HTML 直接使用。

Web ZIP 需要解压并通过 HTTPS 提供访问，本机预览可使用 `localhost` HTTP。完整内容应部署在站点根路径，当前不支持站点子路径。自行部署见[部署指南](deployment.md)。

### 校验下载文件

同时下载同一 Release 的校验清单，比较文件的 SHA-256 与清单中的对应值。例如，在 Windows PowerShell 中进入下载目录，将以下占位文件名替换为实际文件名后运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\aura-portable-vX.Y.Z.html"
```

输出的 `Hash` 应与清单中该文件的校验值一致，字母大小写不影响比较。若不一致，重新下载后再检查。

## 导入书籍

首次使用时书架为空。

1. 在书架选择“全部书籍”或一个分类。
2. 点击顶部“导入”，选择一本或多本 `.txt` 或 `.epub` 文件。
3. 等待导入完成，再点击书封开始阅读。部分文件未导入或批次中断时，对话框会列出结果和原因，已成功导入的书籍会保留。

在具体分类内导入会归入该分类；在“全部书籍”中导入会归入“收藏”。同一内容可以重复导入，每本书分别保存阅读进度。

### 格式说明

| 格式 | 阅读方式                                                                   | 主要限制                                                                |
| ---- | -------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| TXT  | 自动识别编码和章节，按当前阅读设置排版。                                   | 无法可靠识别或严格解码时拒绝导入。                                      |
| EPUB | 支持 EPUB 2/3 的可重排版式，保留章节、基本文本结构、图片、表格和书内链接。 | 不支持 DRM、固定版式、音视频及其他交互内容；不复刻原书 CSS 或嵌入字体。 |

不支持的文件会显示具体原因。更改扩展名不会转换格式。

#### TXT 编码与章节

Aura 自动识别 UTF-8、GB18030、Big5 和带 BOM 的 UTF-16，不提供手动选择编码。遇到编码提示时，请用文本编辑器将原文件另存为 UTF-8 后重试。

目录根据文本中的章节标题生成，例如“第一章”或“Chapter 1”。没有识别到标题时，整本书显示为“全文”；普通的“1. 标题”不会自动分章，以免把正文列表当作目录。

#### EPUB 目录与内容

章节遵循书中的阅读顺序和目录。同一个正文文件中的多个目录锚点也可分别进入；点击书内链接可跳到对应内容。原书的脚本不会执行，外部资源不会加载，排版使用 Aura 的阅读设置。需要从外部加载图片或包含不支持内容的 EPUB 会被拒绝，避免导入后缺少正文。

目前单本 EPUB 最大 256 MiB，最多包含 10,000 个归档条目。归档展开后的总大小不超过 512 MiB，单个资源不超过 64 MiB，单个 XML 文件不超过 16 MiB；正文结构过于复杂的文件也会被拒绝。

## 查找与整理

桌面在左侧选择分类；手机点击左上角导航按钮。分类由应用预设，不支持自建，空分类也会显示；难以归类的书籍可放入“其他”。

- **查找书籍**：顶部搜索框按书名筛选当前分类。查找整个书架时，先选择“全部书籍”。
- **继续阅读**：点击书封，恢复已保存的阅读位置。书目下方显示章节位置。
- **移动分类**：点击书目下方分类名称右侧的下拉箭头，选择目标分类。
- **导出原文件**：点击书目下方的“更多操作”，选择“导出”，将导入时的文件交给浏览器保存。下载使用原文件名，字节内容与导入时一致，不包含 Aura 的分类、阅读进度或外观设置。
- **删除书籍**：在书目的“更多操作”中选择“删除”并确认，移除该书及其进度。
- **清空书架**：打开导航底部的“管理与帮助”，选择“清空书架”并确认，删除所有分类中的书籍与进度，保留外观设置。

从阅读器返回时，会恢复之前的分类、搜索和列表位置。删除与清空无法撤销，但不会删除设备上的原始书籍文件。

## 阅读与目录

默认使用“覆盖”逐页阅读，阅读位置自动保存。在阅读工具的“设置 → 常规设置 → 翻页方式”中切换：

| 翻页方式 | 阅读行为                                     |
| -------- | -------------------------------------------- |
| 覆盖     | 逐页阅读，新页覆盖当前页。                   |
| 平移     | 逐页阅读，前后页面同时横向移动。             |
| 上下     | 连续上下滚动，可以停在任意位置并接续相邻章。 |
| 无动画   | 逐页阅读，立即显示目标页。                   |

分页时，一章会按当前字体、字号和可用空间分成多页。最后一页继续向前，进入下一章第一页；第一页往回翻，进入上一章最后一页。到全书开头或结尾时停止，不会循环。工具中的“本章”页码只对应当前排版，调整字号、窗口或横竖屏后会重新计算；阅读位置根据正文内容恢复。

系统开启“减少动态效果”，或浏览器不支持翻页动画所需能力时，分页直接切换，仍保留所选翻页方式。横向轻扫在松手后触发翻页，页面不会跟随手指拖动。

### 使用阅读工具

桌面右侧操作栏常驻；手机、窄屏或以触摸为主要输入的设备使用移动布局，轻点正文中间区域显示或收起工具。

| 操作           | 桌面布局                   | 移动布局                                       |
| -------------- | -------------------------- | ---------------------------------------------- |
| 上一页、下一页 | 点击右侧对应按钮           | 唤出工具后点击前后按钮，或使用下述触屏翻页手势 |
| 连续上下阅读   | 选择“上下”，用滚轮或触控板 | 选择“上下”，上下滑动正文                       |
| 目录、设置     | 点击右侧对应按钮           | 轻点正文中间区域，再点击底部对应按钮           |
| 全屏、返回书架 | 点击右侧“全屏”或“书架”     | 唤出工具后，点击底部“全屏”或“书架”             |

触屏分页时，正文左侧轻点或向右轻扫回到上一页，右侧轻点或向左轻扫进入下一页。“上下”方式保留浏览器原生滚动，前后按钮改为“上一屏”“下一屏”，正文两侧轻点和横扫不翻页。分页时也可用滚轮或触控板前后翻页，一段连续滚动及其惯性只触发一次翻页。

鼠标拖动和触屏长按用于选择文字，双指操作保留浏览器缩放。链接、表格等内容优先响应自身操作，需要滚动的表格或代码区可在内部滚动，不会触发正文翻页。

正文获得焦点时，`←`、`PageUp`、`Shift+Space` 返回上一页或上一屏，`→`、`PageDown`、`Space` 进入下一页或下一屏；“上下”方式按屏滚动，其他方式逐页切换。操作搜索框、设置控件或选中文字时，这些按键保留原有行为。

点击“目录”后可按章节名称查找，选择章节会进入章首。标题栏的定位图标会清除查找条件，并将目录滚动到当前章节，不改变正文位置。EPUB 书内链接进入其指向的内容。

移动工具显示时，可以查看书名、当前章节和全书阅读进度；分页方式还显示本章页码。工具覆盖在正文上，显隐不改变正文尺寸与阅读位置；翻页或通过目录跳转后自动收起，滚动或长按选字不会切换工具。键盘用户可用 `Tab` 找到“显示阅读工具”入口。

`Escape` 先关闭打开的目录或设置面板，没有面板时收起移动工具。全屏按钮仅在浏览器支持时显示。桌面操作栏和移动工具均显示全书阅读进度。

设置、目录、移动分类抽屉和“关于 Aura”也可点击面板外的遮罩关闭；点击面板内部空白或从内部拖出不会关闭。关闭目录保留其浏览位置，关闭设置会撤销尚未提交的预览。删除、清空等确认窗口仍通过确认、取消或关闭按钮处理。

## 调整外观

在书架顶部选择“外观”，或在阅读工具中选择“设置”；窄屏书架上可能只显示设置图标。书架与阅读器分别保存设置；阅读设置用于所有书籍。

书架默认使用“晴空”主题与“木纹”材质；阅读器默认使用“纸页”主题与“标准”材质，两页的网页背景纹理均默认关闭。已保存的选择优先于这些默认值。

面板保留“主题”和“常规设置”两个同级分区。两页都先显示主题，再显示常规设置；高频项直接展示，其他设置按用途分组：

| 页面   | 分组       | 设置                                       | 展示方式 |
| ------ | ---------- | ------------------------------------------ | -------- |
| 书架   | 常规设置   | 字体、封面大小、书名字号                   | 直接显示 |
| 书架   | 封面与材质 | 封面造型、封面配色、界面材质、网页背景纹理 | 按需展开 |
| 阅读器 | 常规设置   | 翻页方式、字体、字号、行距、页边留白       | 直接显示 |
| 阅读器 | 排版细调   | 字间距、段间距、桌面阅读宽度               | 按需展开 |
| 阅读器 | 配色与材质 | 文字颜色、阅读背景、界面材质、网页背景纹理 | 按需展开 |

折叠分组可以同时展开；在同一页面关闭设置再打开，会保留展开状态。折叠不影响已保存的选择，也不会改变还原范围。

拖动滑块时数值立即更新，暂停约 100 毫秒后预览页面效果，松手后立即应用并保存；其他外观控件实时生效。关闭面板会取消尚未提交的预览。手动设置的文字颜色、阅读背景等优先于主题，切换主题不会清除这些设置。窄屏按可用空间显示正文，保留桌面阅读宽度的首选值。

阅读器的“字间距”可在标准间距上增加字号的 0–20%，显示为“标准”或“+5%”等。想让正文更疏朗时逐步增加即可。“页边留白”通过滑块同时调整正文左右两侧，范围为当前布局默认留白的 50%–150%，手机也可使用；系统安全区域仍会保留。这两项调整都会重新排版，并保留当前阅读内容的位置。

### 选择书封样式

书架的“封面与材质”提供两项书封选择：

- **封面造型**：默认“立体”，保留书脊、页芯与投影；“平面”收起这些立体细节，保留同一书架布局和材质。
- **封面配色**：默认“缤纷”，不同书籍保持各自的配色；“随主题”让书封使用统一的主题色调，切换主题时同步变化。

### 选择界面材质

展开书架的“封面与材质”或阅读器的“配色与材质”，选择“界面材质”。材质跟随当前主题配色，切换主题会保留选择：

| 材质     | 效果                                             |
| -------- | ------------------------------------------------ |
| 标准     | 保留清晰的纯色表面与原有光影。                   |
| 木纹     | 在主题配色上加入连续纤维木理与柔和木面光泽。     |
| 毛玻璃   | 界面透出柔化的背景色彩，配合透明边缘与柔和光影。 |
| 细纹纸   | 界面表面带纸面颗粒、细纹和叠纸边缘。             |
| 柔瓷     | 以柔和高光、渐变和内侧阴影表现温润的表面。       |
| 亚麻     | 以经纬交错的细纹和柔和包边表现织物表面。         |
| 拉丝金属 | 使用定向细纹、反光带和清晰边缘表现拉丝表面。     |
| 皮革     | 以细腻压纹、缝边和柔和边缘表现皮革表面。         |
| 砂岩     | 以矿物颗粒、细小斑点和哑光边缘表现石材表面。     |

材质作用于导航、书封、面板、菜单和控件，页面底层背景默认只协调配色与光影。普通控件使用较淡的同类表面，主要按钮保留醒目的操作色，选中状态与原生输入仍保持清晰。

界面材质不给正文添加纹理或透明效果。书架与阅读器分别保存；系统要求减少透明度、使用高对比度模式或浏览器不支持模糊时，会使用相应的实色表面，保留所选材质。

### 添加网页背景纹理

“网页背景纹理”与界面材质位于同一分组，默认关闭，两页分别保存。开启后，网页背景使用当前界面材质；切换材质时背景同步变化，阅读正文始终保持不透明的纯色背景。“标准”材质本身没有纹理，开启后也不会增加纹理。

切换主题或界面材质会保留开关状态。阅读器窄屏下正文占满页面时，外侧背景不可见。高对比度模式下隐藏纹理，保留已保存的选择。

### 使用本机字体

默认字体为“平台默认”。支持读取本机字体的浏览器会在字体菜单中提供“读取本机字体…”，授权后即可选择；安装新字体后用“刷新本机字体…”更新列表。读取或刷新只更新选项，不会自动更改当前字体。

读取本机字体不会下载或上传字体文件，只保存所选字族名称。不支持读取、拒绝授权或 portable 页面受限时，仍可使用平台默认。所选字体不可用或缺少某个字时，由浏览器回退显示。

### 重置外观

- 单项“还原”清除该项的手动设置，重新使用默认值；手动选回相同数值不等于还原。按钮仅在有可还原设置时显示，成功后立即隐藏，焦点回到对应控件。
- “主题”旁的“还原”恢复默认主题，保留常规设置。
- “常规设置”旁的“恢复默认”恢复全部常规项，包括折叠组中的设置，保留主题。
- “重置书架设置”或“重置阅读设置”恢复对应页面的主题和常规设置，不影响另一页、书籍或阅读进度。

## 本地数据与 portable 注意事项

导入的原文件、阅读所需的内容与阅读进度保存在当前浏览器的本地数据库中，不会上传；外观也在本地保存。为支持原样导出，Aura 保留完整原文件；TXT、EPUB 还会保存解析后的阅读内容，因此存储占用可能大于原文件大小。同格式且字节相同的文件共享内容存储，每本书的分类和进度独立保存。

请保留原始书籍文件，或使用书架的“导出原文件”另存副本。导出只保留原文件，不是整个 Aura 书架的备份。清除网站数据、浏览器清理、更换浏览器配置或存储空间不足，可能导致数据不可用。

不同设备、浏览器配置和站点地址之间不会自动同步书架。portable HTML 只包含阅读器程序，不包含已导入的书籍与进度；复制 HTML 后需在新环境重新导入书籍。移动或重命名 HTML 后能否访问原书架由浏览器的本地文件存储规则决定，不应将它当作书架备份。

### 从旧版升级

从 v8.0.0 升级无需重置书架或重新导入，原有书籍、分类和阅读位置继续保留。旧的正文纸面纹理选项已移除，其选择不会转为网页背景纹理；新的背景纹理开关默认关闭，其他有效外观设置继续保留。

从 v7.x 或更早版本升级时，v8.0.0 引入的分页阅读使用了不同的进度保存结构，不转换这些旧版数据。升级前保留原始书籍文件，或在旧版中使用“导出原文件”保存副本。打开新版后，按下节步骤确认重置全部数据，再重新导入书籍；旧阅读进度、分类和外观不会保留。Aura 不会因升级自动清空数据。

### 重置全部数据

1. 保留原始书籍文件，并关闭其他 Aura 标签页或窗口。
2. 打开书架导航底部的“管理与帮助”，选择“重置全部数据”。
3. 阅读确认提示并确认。Aura 会清除书籍、阅读进度、外观和当前页面的会话状态，然后重新加载。

重置无法撤销。若提示数据库被占用，关闭其他 Aura 页面后会自动继续。重置不会更新 portable HTML；使用新版本需要下载并打开对应文件。
