# 使用指南

Aura 用于阅读自己导入的 TXT 文件。无需账户，书籍、阅读进度与外观保存在当前浏览器中。

## 打开 Aura

日常使用可以直接打开[在线版](https://aura.allurx.io)。需要离线打开时，从 [GitHub Releases](https://github.com/allurx/aura/releases) 下载 portable HTML，用浏览器打开该文件。

### 安装应用

联网打开 Web 版后，可以通过浏览器的安装入口添加到桌面或主屏幕。是否提供入口取决于浏览器及系统支持，具体操作见官方说明：

- [Chrome：安装 Web 应用](https://support.google.com/chrome/answer/9658361?hl=zh-Hans&co=GENIE.Platform%3DDesktop)
- [Edge：将网站安装为应用](https://support.microsoft.com/zh-cn/edge/install-manage-or-uninstall-apps-in-microsoft-edge)
- Safari：[iPhone 添加到主屏幕](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)、[Mac 添加到程序坞](https://support.apple.com/zh-cn/guide/safari/ibrw9e991864/mac)

没有安装入口时，继续使用网页即可。安装后的 Aura Web 版仍需联网打开；portable 用于离线打开，不提供应用安装入口。主屏幕模式也不等同于网页全屏，系统状态栏与手势区域由设备管理。

安装不提供书籍备份或跨设备同步。网页与独立应用窗口可能使用不同的存储空间，安装后应先确认书架是否可用，并保留原始 TXT。

### 选择下载文件

个人离线阅读选择普通 portable 版即可。下表中的 `vX.Y.Z` 为所选 Release 的版本号，下载时以附件的实际文件名为准。

| 文件                                   | 用途                              |
| -------------------------------------- | --------------------------------- |
| `aura-portable-vX.Y.Z.html`            | 普通单文件版，用浏览器直接打开。  |
| `aura-portable-obfuscated-vX.Y.Z.html` | 混淆单文件版，打开方式相同。      |
| `aura-web-vX.Y.Z.zip`                  | 普通 Web 包，用于部署网站。       |
| `aura-web-obfuscated-vX.Y.Z.zip`       | 混淆 Web 包，部署方式相同。       |
| `aura-vX.Y.Z-SHA256SUMS.txt`           | 上述四个文件的 SHA-256 校验清单。 |

普通版与混淆版提供相同的阅读功能。GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码包，不能作为 portable HTML 直接使用。

Web ZIP 需要解压并通过 HTTPS 提供访问，本机预览可使用 `localhost` HTTP。完整内容应部署在站点根路径，当前不支持站点子路径。自行部署见[部署指南](deployment.md)。

### 校验下载文件

同时下载同一 Release 的校验清单，比较文件的 SHA-256 与清单中的对应值。例如，在 Windows PowerShell 中进入下载目录，将以下占位文件名替换为实际文件名后运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\aura-portable-vX.Y.Z.html"
```

输出的 `Hash` 应与清单中该文件的校验值一致，字母大小写不影响比较。若不一致，重新下载后再检查。

## 导入书籍

首次使用时书架为空。

1. 在书架选择“全部书籍”或一个分类。
2. 点击顶部“导入 TXT”，选择一本或多本 `.txt` 文件；窄屏上可能只显示加号图标。
3. 等待导入完成，再点击书封开始阅读。部分文件未导入或批次中断时，对话框会列出结果和原因，已成功导入的书籍会保留。

在具体分类内导入会归入该分类；在“全部书籍”中导入会归入“收藏”。同一内容可以重复导入，每本书分别保存阅读进度。

### 编码与目录注意事项

Aura 自动识别 UTF-8、GB18030、Big5 和带 BOM 的 UTF-16，不提供手动选择编码。无法可靠识别或严格解码的文件会被拒绝。遇到编码提示时，请用文本编辑器将原文件另存为 UTF-8 后重试；更改扩展名不会转换编码。

目录根据文本中的章节标题生成，例如“第一章”或“Chapter 1”。没有识别到标题时，整本书显示为“全文”；普通的“1. 标题”不会自动分章，以免把正文列表当作目录。

## 查找与整理

桌面在左侧选择分类；手机点击左上角导航按钮。分类由应用预设，不支持自建，空分类也会显示；难以归类的书籍可放入“其他”。

- **查找书籍**：顶部搜索框按书名筛选当前分类。查找整个书架时，先选择“全部书籍”。
- **继续阅读**：点击书封，恢复已保存的阅读位置。书目下方显示章节位置。
- **移动分类**：在书目下方直接选择目标分类。
- **删除书籍**：点击书目的删除按钮并确认，移除该书及其进度。
- **清空书架**：在导航底部选择“清空书架”并确认，删除所有分类中的书籍与进度，保留外观设置。

从阅读器返回时，会恢复之前的分类、搜索和列表位置。删除与清空无法撤销，但不会删除设备上的原始 TXT 文件。

## 阅读与目录

正文按章节纵向滚动，阅读位置自动保存。桌面右侧操作栏常驻；手机、窄屏或以触摸为主要输入的设备使用移动布局，轻点正文中间区域显示或收起工具。

| 操作           | 桌面布局               | 移动布局                             |
| -------------- | ---------------------- | ------------------------------------ |
| 上一章         | 点击右侧“上一章”       | 轻点正文左侧，或向右横向轻扫         |
| 下一章         | 点击右侧“下一章”       | 轻点正文右侧，或向左横向轻扫         |
| 目录、外观     | 点击右侧对应按钮       | 轻点正文中间区域，再点击底部对应按钮 |
| 全屏、返回书架 | 点击右侧“全屏”或“书架” | 唤出工具后，点击底部“全屏”或“书架”   |

点击“目录”后可按章节名称查找，选择章节进入阅读。正文获得焦点时，也可用左右方向键切章。以上操作切换整个章节；上下滑动或滚动用于阅读当前章。

移动工具显示时，可以查看书名、当前章节和全书阅读进度。工具覆盖在正文上，不改变阅读位置；切章后自动收起，滚动或长按选字不会切换工具。键盘用户可用 `Tab` 找到“显示阅读工具”入口。

`Escape` 先关闭打开的目录或外观面板，没有面板时收起移动工具。全屏按钮仅在浏览器支持时显示。桌面操作栏和移动工具均显示全书阅读进度。

## 调整外观

在书架顶部或阅读工具中选择“外观”；窄屏书架上可能只显示设置图标。书架与阅读器分别保存设置，调整一页不影响另一页。

面板分为“主题”和“常规设置”。主题控制整体配色，常规设置按页面提供：

| 页面   | 常规设置                                                   |
| ------ | ---------------------------------------------------------- |
| 书架   | 字体、封面大小、书名字号                                   |
| 阅读器 | 字体、字号、行距、段间距、文字颜色、阅读背景、桌面阅读宽度 |

调整时实时预览，完成单项操作后自动保存；关闭面板会取消尚未提交的预览。手动设置的文字颜色、阅读背景等优先于主题，切换主题不会清除这些设置。窄屏按可用空间显示正文，保留桌面阅读宽度的首选值。

### 使用本机字体

默认字体为“平台默认”。支持读取本机字体的浏览器会在字体菜单中提供“读取本机字体…”，授权后即可选择；安装新字体后用“刷新本机字体…”更新列表。读取或刷新只更新选项，不会自动更改当前字体。

应用不下载或上传字体，只保存所选字族名称。不支持读取、拒绝授权或 portable 页面受限时，仍可使用平台默认。所选字体不可用或缺少某个字时，由浏览器回退显示。

### 重置外观

- 设置项旁的重置图标只恢复该项。
- “主题”旁的重置图标恢复默认主题，保留常规设置。
- “常规设置”旁的重置图标恢复本页常规设置，保留主题。
- “重置当前页面”恢复本页全部外观，不影响另一页、书籍或阅读进度。

## 本地数据与 portable 注意事项

导入的文本与阅读进度保存在当前浏览器的本地数据库中，不会上传；外观也在本地保存。请保留原始 TXT：清除网站数据、浏览器清理、更换浏览器配置或存储空间不足，可能导致数据不可用。

不同设备、浏览器配置和站点地址之间不会自动同步书架。portable HTML 只包含阅读器程序，不包含已导入的书籍与进度；复制 HTML 后需在新环境重新导入 TXT。移动或重命名 HTML 后能否访问原书架由浏览器的本地文件存储规则决定，不应将它当作书架备份。

### 重置全部数据

1. 保留原始 TXT，并关闭其他 Aura 标签页或窗口。
2. 在书架导航底部选择“重置数据”。
3. 阅读确认提示并确认。Aura 会清除书籍、阅读进度、外观和当前页面的会话状态，然后重新加载。

重置无法撤销。若提示数据库被占用，关闭其他 Aura 页面后会自动继续。重置不会更新 portable HTML；使用新版本需要下载并打开对应文件。

在书架导航中选择“关于 Aura”，可查看项目链接与许可信息；手机先打开左上角导航。点击“项目源码”前往 [GitHub 仓库](https://github.com/allurx/aura)，阅读说明或[反馈问题](https://github.com/allurx/aura/issues)。访问 GitHub 需要联网。
