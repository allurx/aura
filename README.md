# Aura

[Aura](https://aura.allurx.io) 是一个轻量的本地电子书阅读器，支持 TXT 和 EPUB。导入自己的书籍，按分类整理书架，接着上次的位置阅读。无需账户，书籍与阅读进度保存在当前浏览器中。

## 特性

- 自动识别 TXT 编码与章节，按 EPUB 目录阅读，保留图片、表格和书内链接。
- 适应桌面与移动阅读，支持目录、键盘和触摸导航。
- 提供多种主题与排版设置，书架和阅读器的外观独立保存。
- 保留导入的原文件，可从书架原样导出。
- 提供 Web 版与单文件 portable 离线版；支持的浏览器可将 Web 版安装为应用。

## 开始阅读

1. 打开[在线版](https://aura.allurx.io)。需要离线打开时，从 [GitHub Releases](https://github.com/allurx/aura/releases) 下载 `aura-portable-vX.Y.Z.html`，用浏览器打开；`vX.Y.Z` 为所选版本号。
2. 点击“导入书籍”，选择 `.txt` 或 `.epub` 文件，再点击书封开始阅读。
3. 通过“目录”切换章节，通过阅读工具中的“设置”调整阅读外观。手机端先轻点正文中间区域唤出工具；下次打开同一本书时会恢复阅读位置。

版本选择、书架整理和详细操作见[使用指南](docs/usage.md)。

### 注意事项

- EPUB 支持无 DRM 的可重排版式，使用 Aura 的阅读排版。具体支持范围见[格式说明](docs/usage.md#格式说明)。
- TXT 编码自动识别。无法可靠识别编码的文件会被拒绝，可另存为 UTF-8 后重试。
- Web 版安装后仍需联网打开；离线使用请选择 portable。安装方式见[使用指南](docs/usage.md#安装应用)。
- 请保留原始书籍文件；书架的“导出原文件”可取回导入时的文件，但不包含分类或阅读进度。浏览器数据不会自动同步，portable HTML 也不包含已导入的书籍和进度；存储与清理说明见[本地数据注意事项](docs/usage.md#本地数据与-portable-注意事项)。
