# Aura

[Aura](https://aura.allurx.io) 是一个轻量、离线优先的 TXT 阅读器。导入自己的文本，在书架中查找和整理，打开后接着上次的位置阅读。

## 特性

- 桌面左侧分类导航，手机抽屉导航；支持书名搜索、移动分类和单书删除。
- 自动识别 TXT 编码，生成章节目录，支持目录搜索和阅读进度恢复。
- 九种主题，书架与阅读器独立保存外观；在同一个面板中调整主题、排版和页面细节。
- 提供普通 Web 版和可直接打开的单文件 portable 版。

## 开始阅读

1. 打开[在线版](https://aura.allurx.io)，或从 [GitHub Releases](https://github.com/allurx/aura/releases) 下载 portable HTML 后在浏览器中打开。
2. 选择“导入 TXT”，导入自己的文本，再点击书籍开始阅读。
3. 通过“目录”切章或“外观”调整阅读效果；手机端先轻点正文中间区域唤出工具。下次打开同一本书时会恢复阅读位置。

版本选择、书架整理和详细操作见[使用指南](docs/usage.md)。

### 注意事项

- 只支持 `.txt`，编码由应用自动识别；无法可靠识别的文件会被拒绝。
- 书籍和进度保存在当前浏览器本地，请保留原始 TXT。清除网站数据或更换浏览器、访问地址可能无法取回原来的书架。
- portable HTML 包含阅读器程序，不包含已导入的书籍与进度。
